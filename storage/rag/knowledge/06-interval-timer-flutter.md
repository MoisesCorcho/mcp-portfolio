# Project: IntervalTimer Pro (Cross-Platform Mobile App)

## Overview & Links
- **Repository**: https://github.com/MoisesCorcho/IntervalTimer
- **Role**: Mobile Application Engineer (Flutter & Dart)

## Architecture & Engineering
- **Core Stack**: Flutter, Dart, Riverpod 2, Drift (SQLite ORM), iOS Dynamic Island / Live Activities, RevenueCat, Google AdMob.
- **Architecture**: Clean reactive state management using Riverpod with strict separation between Domain, Application, and Data layers.
- **Native Platform Channels**: Swift / iOS Live Activity bindings displaying remaining interval times on the Dynamic Island and Lock Screen.

## Key Technical Achievements & What Moisés Did
- Modeled audio ducking and custom haptic feedback patterns synchronized with interval transitions.
- Integrated RevenueCat for in-app purchases, recurring subscription tiers, and entitlement validation.
- Implemented offline-first persistence using Drift SQLite with schema migrations.

## What Moisés CAN Build Based on This
- Cross-platform mobile applications for iOS and Android in Flutter.
- Offline-first SQLite local databases and state management with Riverpod.
- Native mobile hardware integrations (audio, haptics, iOS Live Activities / Dynamic Island).
- In-App Purchases and subscription flows via RevenueCat.

## Limitations
- Does not build native Android apps in Java/Kotlin or iOS apps in Objective-C from scratch (specializes in Flutter / Dart for cross-platform efficiency).
