# Project: InfoReal (Enterprise News Portal & CMS)

## Overview & Links
- **Official Production Domain**: https://www.inforeal.com.co/
- **Repository**: https://github.com/MoisesCorcho/NoticiasInfoReal
- **Role**: Lead Web Developer & DevOps Engineer

## Architecture & Engineering
- **Core Stack**: Laravel 12, Filament v3, Livewire 3, Tailwind CSS 4, MySQL, Docker.
- **Domain**: High-traffic regional digital newspaper delivering breaking news, multimedia journalism, and editorial categorization.
- **Content Management**: Customized Filament CMS allowing journalists and editors to manage rich text articles, image galleries, and social media embeds.

## Key Technical Achievements & What Moisés Did
- Optimized database indexing and query caching to withstand sudden traffic spikes during breaking news events.
- Configured automated SEO OpenGraph meta tags, RSS feeds, and responsive typography for mobile readership.
- Implemented production deployment with Docker and managed continuous updates on Linux VPS.

## What Moisés CAN Build Based on This
- Editorial content platforms, media portals, and high-readership blogs.
- Custom CMS systems tailored for non-technical content creators.
- Performance tuning for high-traffic read-heavy MySQL workloads.
