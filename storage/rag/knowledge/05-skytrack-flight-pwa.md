# Project: SkyTrack (Real-Time PWA & Flight Price Intelligence)

## Overview & Links
- **Repository**: https://github.com/MoisesCorcho/flightPrices
- **Role**: Full-Stack & PWA Architect

## Architecture & Engineering
- **Core Stack**: Laravel 13, Livewire 4, Flux UI, Tailwind CSS 4, Service Worker (PWA), Firebase Cloud Messaging (FCM), SerpApi.
- **Mobile First & PWA**: Offline-first caching strategy via Service Workers, web app manifest, and mobile push notifications.
- **Price Tracking Engine**: Automated scheduled scrapers querying SerpApi / Google Flights to detect price drops across multi-leg routes.

## Key Technical Achievements & What Moisés Did
- Built real-time price volatility charts and automated threshold notification triggers.
- Integrated Firebase Web Push protocol allowing desktop and mobile browsers to receive alerts without installing native app store packages.
- Engineered modern UI with Flux UI and Livewire 4 for instant reactive state transitions.

## What Moisés CAN Build Based on This
- Installable Progressive Web Apps (PWAs) with push notifications and background service workers.
- Real-time data scraping, scheduling, and price alerting engines.
- Reactive dashboards with Livewire and Tailwind CSS.
